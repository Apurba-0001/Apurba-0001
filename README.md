## Featured Projects

### 🏔️ [TiyraSense](https://github.com/Apurba-0001/TiyraSense) · SIH 2026 (PS 26002)
**AI-powered smart logistics and accessibility intelligence platform for North East India.** A risk-aware decision-support system for hill supply routes that combines weather forecasts, PostGIS terrain data, historical road-cut frequency, and crowdsourced field reports.

- Assesses current road accessibility and predicts 2-hour disruption probability with calibrated ML
- Scores segment risk with deterministic, auditable weighting formulas
- Recommends the safest viable route while keeping the fastest route visible for comparison
- Works offline-first, with encrypted local storage and automatic sync when connectivity returns
